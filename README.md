<h1>Personal_mortgage_calculator</h1>

這是一個基於 C# Windows Forms (WinForms) 開發的專業房貸計算器。本專案專為需要精確試算房貸負擔、分析還款結構的購屋族設計。除了基礎的本息平均攤還公式外，亦支援寬限期 (Grace Period) 設定與視覺化圖表分析。#

使用者輸入房屋總價、自備款比例、貸款利率、貸款年限、貸款年限等資料，自動生成日後需繳的金額。

計算功能:

精確房貸計算：支援房屋總價、自備款比例、貸款利率及年限設定。
寬限期支援：可選填寬限期年數，自動計算寬限期內（只付息）與期後（本息攤還）的差異。

詳盡輸出指標：
貸款總金額、每月應繳金額（動態區分寬限期內外）、首期利息與首期本金支出、累計總利息支出、總還款金額

數據視覺化：整合 Chart 控制項，以圓餅圖直觀呈現「貸款本金」與「總利息支出」的比例。

輸入驗證：具備即時錯誤偵測機制（如：請輸入有效房屋價格），確保運算穩定性。

------------------------------------------

**測試範例**

若要驗證邏輯準確性，可輸入以下範例數據：<br>
房屋總價：1,250 萬元<br>
自備款比例：20%<br>
利率：2.2%<br>
年限：30 年<br>
寬限期：5 年<br>
*預期結果：貸款金額 1,000 萬，寬限期月付約 18,333 元。*
